# Studio Animasi Netizen

Bikin video animasi 3D low-poly interaktif untuk Instagram Reels — kerajaan yang tumbuh dari follower dan
komentar — cukup dengan ngobrol bersama Claude.

**Mulai dari sini:** buka file PDF panduan "MULAI DI SINI", lalu pakai pesan-pesan di folder `prompts/`.

| Folder | Isi |
|---|---|
| `prompts/` | pesan siap salin untuk Claude (ini yang kamu pakai) |
| `episodes/` | file cerita setiap video (dibuat oleh Claude) |
| `videos/` | video hasil jadi, cover, dan logo |
| `engine/`, `tools/`, `docs/`, `assets/` | mesin studio (tidak perlu dibuka) |

Lisensi: boleh dipakai untuk membuat video sebanyak-banyaknya untuk akun pribadi maupun komersial.
